# 👋 Hello / 你好

I build **ScoreLens** — a football score-probability prediction & data journalism platform.

- ⚽ **[scorelens.net](https://scorelens.net)** — Dixon-Coles double-Poisson model + Elo ratings layer, covering Europe's top-5 leagues and national teams with full score-probability matrices, out-of-sample backtest metrics, and multi-language football news aggregation
- 📊 Strictly out-of-sample backtest: club top-pick accuracy **55.6%** / national teams **57.2%**
- 📰 News aggregated hourly from global football outlets — English, 中文, 日本語, Español, Português, Français, Deutsch, Italiano, Bahasa, العربية
